Figure 8. Illustration of basic functionalities of planning module. 

Planning primarily proceeds through backward chaining / goal regression. Query target actions are matched with candidate actions, which then seed backward chaining. Planning can thus handle multi-stage or compound queries. Backward chaining can also proceed directly on goal conditions. For details, please see section 3.4. 

Planning is a follow-on module to search. Planning query terms are extracted from query search terms. 

Below is an example, with query: how to clean a gold bar and then bury it in the backyard? 

Two plans were generated that cover both target actions. Both plans use chained actions from the memory "cleaning the washing machine (components)" for the "clean" target action, and an action "bury_material_layer" for the "bury" target action. 

A larger dataset would be needed to test planning more carefully.
